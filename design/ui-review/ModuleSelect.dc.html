PROPOSAL 01 · MOSTLY SHIPPED
Open on your case, not on an address
Scanning is setup, not a step you repeat. Remember what answered, and let the list be the way in. The remembering landed; the list is on screen but is not yet the handle.
Today, in the firmware
200e Modules
Addr 5C  251 A
encL:scan B:probe  2
 5C 251 A
 28 259 A
The responder list is drawn, by name, and it now survives a power cycle — so the ~49 s sweep is paid once, not every morning. But the inverted 5C is still the right encoder's target: you dial hex, and the list beside it is a read-out rather than a cursor. A marker dot shows which row the dialled address is sitting on.
Still proposed
200e Modules
>251 A      5C
 259 A      28
 210        20

encR:open  encL:rescan
The encoder walks the list; the address moves right — still visible, no longer the handle. That last step is the one that has not been taken, and it is the one that turns "we remembered your case" into "you never type an address again".
How the memory actually works, since the original proposal guessed at "one 64-bit word": the found set is a bitmap over the module table, not over raw addresses, and it is stored in the app's own app-data chunk together with the table's length. If a firmware update changes the table, the saved set is refused rather than reinterpreted as different modules. It is written only at a quiescent moment — never during a scan, probe, read, write or while serving the card — because the save is a whole-EEPROM rewrite, not a field poke. Rescan is manual, on encL.
Why it earns the rows
The list replaces the address field, the progress line and the hint line — three rows spent on a process, returned to content. Names are already known: identification on this bus is an address→model table, so the instrument can name what it found without asking anything.
The tradeoff, now live
A remembered module that has since been unplugged still appears — you find out when a read fails. Verifying the list on every open would just be the scan again, wearing a different hat. Rescan is the cure, and it stays one press away. This is no longer a hypothetical cost of a proposal: the persistence shipped, so a stale row is something a player can meet today.
A clone squats the address of whatever it emulates — the CSR answers at 0x20 as a “210”. The name is a strong hint, never a proof, which is why every name on these screens is prefixed ? and the address stays beside it rather than being hidden. (The hedge was ~ when this artboard was drawn. That character is not in the 6×8 font — 92 glyphs from 0x20, ending at { — so all four sites drew a noise block that read as display corruption, and the screen then asserted the model as fact.)
